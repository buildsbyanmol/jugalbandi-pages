Two good tools.
One unfinished conversation.

Built around a small, recurring problem: carrying the whole story yourself.

Claude Code knows what happened in its session. Codex knows what happened in its own. Moving the work between them still asks the person in the middle to gather decisions, failed approaches, changed files, and unfinished tasks.

Jugalbandi begins there: the cost of starting over when the tools are already capable.

A record that belongs to the project

The core idea is an independent local record with provenance. A handoff should tell the next agent what matters, where it came from, and what has already failed. It should preserve continuity without requiring one master agent to own everyone's memory.

Test the handoff before building the workspace

The product plan starts with hooks and a CLI. Its north star is handoff cost: the number of human prompts after a harness switch until the new agent's first useful action. The desktop workspace follows a validation gate. That is a proposed measurement plan, not a reported improvement.

A little जुगलबंदी

The landing page tells this idea through a conversation. Claude works, Jugalbandi gathers the notes, and Codex continues. An illustrated manuscript becomes the project record. A plum decision seal marks the moment the human is needed.

The cast mixes two original gallery pets with our own soft vector companions. Paperclip is by Vlad T.; Nickel File Ledger, the smiling notebook companion, is by Federico Cachero. Their rounded silhouettes and small, friendly faces set the mood. Each is an individual agent. Claude Code, Codex, and the planned Cursor adapter are their environment groups; Jugalbandi brings selected participants into a shared workspace. The stage takes inspiration from Indian miniature illustration and musical exchange. Hindi stays in Devanagari, with technical language in English where natural.

The website today

This is a responsive static website with scripted demonstrations and an interactive product mockup. The mock puts a command and conversation at the center. A retrying membership-billing webhook brings a plan, a race-condition review, a human decision, and a fix into one thread. Agents, code events, and sample quota sit alongside it. It does not run agents, show actual account usage, save decisions, or collect account usage. Beta registration is a separate Google Form that collects an email address and desktop preference when you submit it.
