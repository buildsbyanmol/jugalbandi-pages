For the curious builders ↗

अपने tools, अपने rules.

Runtime
Node.js 24 · TypeScript · Zod
Capture
Official hooks → redacted spool → one local daemon
Storage
Append-only JSONL → rebuildable SQLite index
Handoff
Recorded events + project/git state + session cursor → relevant packet
Bridge
Stateless stdio MCP shim → agent Unix socket → typed operations
Human control
CLI and planned workspace → separate human Unix socket
Gates
Native controls and hook/git gates. Gate checks do not depend on a running daemon.
Workspace
CLI first. Tauri desktop with a Node sidecar is planned.
Later recall
SQLite FTS default; optional self-hosted mem0 with local embeddings.

Existing harnesses retain their safety and permissions. Gate coverage depends on the available mechanism. Jugalbandi keeps a local project record; the connected model providers still process requests in their own environments.
